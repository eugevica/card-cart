# 🛒 Card-Cart

**Card-Cart** es un ecommerce desarrollado con **React** para la compra de diversos juegos con cartas. En su navegación se puede visualizar los juegos de cartas en oferta, las referencias de sus detalles, agregarlos al carro de compras y completar una orden de compra utilizando bases de datos de Firebase.

---

## ✨ Funcionalidades

- 📦 Listado de productos.
- 🔍 Visualización del detalle de cada producto.
- 🏷️ Filtrado de productos por categoría.
- 🛒 Agregado de productos al carro de compra.
- ✅ Generación de la orden de compra.

---
